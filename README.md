\# Hotel Reservation System



\## Project Overview



The Hotel Reservation System is a Java-based desktop application developed using Java Swing. It helps users manage hotel guests, room bookings, reservations, and check-outs through a simple graphical interface.



\## Technologies Used



\* Java

\* Java Swing

\* AWT

\* VS Code

\* Git and GitHub



\## Features



1\. Add Guest

2\. View Rooms

3\. Book Room

4\. Search Booking

5\. Cancel Booking

6\. Check Out



\## Available Rooms



\* 101

\* 102

\* 201

\* 202

\* 301



\## How to Run



1\. Clone or download this repository.

2\. Open the project folder in VS Code.

3\. Open the terminal.

4\. Compile the Java file:



```bash

javac -d src src/HotelReservationSystem.java

```



5\. Run the application:



```bash

java -cp src HotelReservationSystem

```
